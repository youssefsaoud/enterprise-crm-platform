# Wireframes

Low-fidelity wireframes for Month 1 are captured as text so the structure can evolve before visual design.

## Login

- Centered login form.
- Email and password fields.
- Submit button.
- Validation error area.

## Dashboard

- Header with app name and current user area.
- Side navigation for CRM modules.
- Summary cards for leads, opportunities, and activities.
- Empty state when no data exists.

## Company List

- Page heading and create action.
- Search field.
- Table with company name, industry, owner, and last activity.
- Empty state for no companies.

## Company Detail

- Company profile header.
- Sections for contacts, opportunities, and activities.
- Edit action near the profile summary.

## Contacts

- Table of contacts with company, email, phone, and owner.
- Create form with required fields and validation messages.

## Leads

- Lead list grouped or filtered by status.
- Assignment control for manager and admin users.
- Qualify and disqualify actions.

## Pipeline

- Column-based opportunity stages.
- Opportunity cards with value, owner, and close date.
- Stage changes planned for later implementation.

## Activity History

- Chronological list of notes, calls, emails, and meetings.
- Each entry shows type, author, timestamp, and related record.
