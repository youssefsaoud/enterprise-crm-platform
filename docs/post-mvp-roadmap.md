# Post-MVP Roadmap

Enhancements after April 2024 belong outside the MVP release scope.

## Product improvements

- Email/calendar integration.
- Advanced reporting exports.
- Bulk import for companies and contacts.
- Notification center for lead and opportunity follow-up.
- Mobile-optimized layouts for field sales.

- Expand service-level backend unit tests.
- Add API contract tests for frontend/backend integration.
- Add container vulnerability scanning in CI.
