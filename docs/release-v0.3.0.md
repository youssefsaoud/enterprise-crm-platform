# Release v0.3.0: Companies And Contacts Management

`v0.3.0` marks the Month 3 CRM milestone.

## Included

- Secured company CRUD API with search, pagination, filtering, validation, and delete conflict behavior.
- Secured contact CRUD API with company relationships, search, pagination, and company-scoped listing.
- Angular company list, detail, create, and edit workflows.
- Angular contact list, detail, create, and edit workflows.
- Company-to-contact navigation and related contact preview.
- API, database, README, and milestone documentation.
