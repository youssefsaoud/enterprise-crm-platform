# Month 8 Backlog: Testing, Security And Stabilization

Month 8 should harden the CRM application for release readiness.

## Candidate Scope

- Backend service/controller regression coverage for auth, RBAC, CRUD, conversion, and dashboard metrics.
- Angular component/service coverage for dashboard, forms, timelines, and error states.
- End-to-end smoke flows for login, company/contact creation, lead conversion, opportunity pipeline, and activity logging.
- Access-control audit for cross-user record isolation.
- Validation, error handling, and slow-network UX polish.
- Migration checks against clean and existing databases.
